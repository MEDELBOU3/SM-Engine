# Contributing to SM Engine

First of all, thank you for your interest in contributing to **SM Engine**!

SM Engine is an open-source 3D engine designed to provide developers with powerful tools for creating, simulating, and developing interactive 2D and 3D experiences.

We welcome contributions from developers, designers, and enthusiasts who want to help improve the engine.

## How to Contribute

There are several ways to contribute to SM Engine:

- **Bug Reports:** Identify and report bugs or unexpected behavior.
- **Feature Requests:** Suggest new features, tools, and improvements.
- **Code Contributions:** Improve existing systems or introduce new functionality.
- **Performance Improvements:** Optimize rendering, physics, memory usage, and overall performance.
- **Documentation:** Improve guides, examples, and technical documentation.
- **UI/UX Improvements:** Help improve the editor interface and user experience.

## Getting Started

1. Fork the SM Engine repository.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your modifications and test them.
5. Commit your changes with a clear and descriptive message.
6. Push your branch to your fork.
7. Open a Pull Request.

## Development Guidelines

To maintain code quality and consistency, please follow these guidelines:

- Write clean, readable, and maintainable JavaScript code.
- Follow the existing project structure and coding conventions.
- Avoid unnecessary dependencies.
- Keep changes focused and well-documented.
- Consider performance and compatibility when modifying engine systems.
- Test your changes before submitting them.

## Pull Request Guidelines

Before submitting a Pull Request:

- Make sure your changes work as expected.
- Clearly describe what you have changed and why.
- Reference related issues when applicable.
- Include screenshots or demonstrations for visual changes.
- Avoid combining unrelated changes in a single Pull Request.

All contributions are subject to review before being merged.

## Reporting Bugs

If you encounter a bug, please open an Issue and provide:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected and actual behavior.
- Your operating system and relevant environment details.
- Screenshots, logs, or error messages when available.

For security vulnerabilities, please follow our [Security Policy](SECURITY.md) instead of opening a public Issue.

## Feature Suggestions

We welcome ideas that can improve SM Engine's capabilities, including:

- Rendering and lighting systems.
- Physics and simulation.
- 2D and 3D development tools.
- Editor workflow and usability.
- Animation and scripting systems.
- Performance and optimization.

Please explain the purpose of your suggestion and how it could benefit the engine.

## Code of Conduct

All contributors are expected to communicate respectfully and professionally.

We encourage constructive discussions, collaboration, and an inclusive environment for everyone.

## License

By contributing to SM Engine, you agree that your contributions will be distributed under the project's existing license.

If you have any questions, feel free to open a discussion in the repository.

**Thank you for helping build SM Engine!**
