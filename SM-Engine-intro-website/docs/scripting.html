JavaScript Scripting API Reference

Technical documentation for SM Engine's built-in Scripting Mode, global API namespace, scene object manipulation, and event system.

Global API Reference

Global Variable Type Description
window.scene THREE.Scene Root 3D scene graph container.
window.camera THREE.PerspectiveCamera Primary viewport perspective camera.
window.renderer THREE.WebGLRenderer WebGL2 graphics renderer instance.
window.selectedObject THREE.Object3D Currently active selected object in the viewport.
window.historyManager HistoryManager Global undo/redo stack manager.
window.v2dManager Viewport2DManager 2D Grease Pencil and canvas drawing controller.

Scripting Code Examples

1. Rotating an Object Every Frame

// Attach rotation animation script
function update(delta) {
    if (window.selectedObject) {
        window.selectedObject.rotation.y += 1.5 * delta;
        window.selectedObject.rotation.x += 0.5 * delta;
    }
}
window.addEventListener('engine:update', (e) => update(e.detail.delta));

2. Spawning Procedural Cubes into History

// Procedural grid spawner
for (let x = -5; x <= 5; x += 2) {
    for (let z = -5; z <= 5; z += 2) {
        const geo = new THREE.BoxGeometry(1, 1, 1);
        const mat = new THREE.MeshStandardMaterial({ color: Math.random() * 0xffffff });
        const mesh = new THREE.Mesh(geo, mat);
        mesh.position.set(x, 0.5, z);
        mesh.name = `Cube_${x}_${z}`;
        
        window.scene.add(mesh);
        window.historyManager.recordObjectLifecycle(mesh, 'add');
    }
}
