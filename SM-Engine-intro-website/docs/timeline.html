Timeline System

The unified timeline (hosted in #timelineBody) drives keyframes, playback and mixer sync for 3D objects, characters, 2D animation and video clips from a single controller: window.SMTimeline.

Core Timeline (sm-timeline-core.js)

The timeline engine lives in js/timeline/sm-timeline-core.js. It maintains per-object keyframe data in window.keyframes[object.uuid] with position, rotation, and scale arrays, and supports multiple interpolation modes (bezier default, plus linear/step variants).

  • Playback — play/pause/stop, loop toggle, playback speed, frame stepping, and current-time scrubbing.
  • Recording — keyframes can be baked automatically as the user transforms objects.
  • Mixer sync — skeleton/morph/armature clips are blended into the same timeline so animation rigs stay in sync with object keyframes.
  • Binary evaluator — an optimized keyframe evaluator (per-frame binary search over key times) is used for long, dense clips.
  • System object filtering — helpers, grids, debug objects and userData.isSystemObject items are excluded from the timeline and hierarchy.
Integration with the scene graph scene.add() is patched at boot: any object added to the scene is automatically registered with the timeline (unless flagged userData.ignoreInTimeline), so keyframing works without manual wiring.

3D Animation & Rig Integration

Character animation is layered on top: animations/charater-animation.js provides the character controller and animations/bone-controller.js the bone rig; the RigManager and AdvancedControlRig (animations/RigSysteme/) connect armature clips to the timeline's mixer. Animation clips (FBX/GLTF) are converted by js/timeline/animation-converter.js into timeline-compatible keyframe tracks.

2D Animation Timeline

The 2D editors ship their own layered timeline: 2D-editor/timeline/AdvancedKeyframeEditor.js manages stroke/frame keys for the 2D brush workspace, with onion-skinning previews and frame exposure controls wired into the same playback clock.

Video & Audio Clips

The video editor (video-editing/video-editor-advanced.js) and the audio graph (js/MetaSoundEditor/) expose clip tracks that the timeline controller can cue; video export is rendered frame-by-frame through SMRenderPipeline (rendering/SMRenderPipeline.js).
