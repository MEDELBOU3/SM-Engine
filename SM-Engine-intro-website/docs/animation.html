3D Animation & Character Rigging

Technical guide to keyframing, timeline playback, Graph Editor Bezier curves, bone armatures, character control rigs, and motion matching.

Timeline & Keyframing

The sm-timeline-core.js module manages animation track channels (Position, Rotation, Scale, Custom Attributes) across a frame counter:

  • Press I in the 3D Viewport to open the Insert Keyframe Menu (Location, Rotation, Scale, LocRotScale).
  • Toggle Auto-Keyframing (Record button) to automatically keyframe any transform changes made in the viewport.
  • Use transport playback buttons (Play, Pause, Step Forward/Backward, Loop Range).

Graph Editor (F-Curve Editor)

Click Graph Editor tab in the bottom drawer to edit keyframe interpolation curves:

Interpolation Type Curve Behavior
Bezier (Default) Smooth acceleration and deceleration using adjustable tangent control handles.
Linear Constant velocity movement between keyframes with straight line interpolation.
Constant (Step) Holds keyframe value until the exact moment of the next keyframe (stop-motion / instant pop).
Bounce / Elastic Procedural spring and bounce overshoot curves at target keyframe values.

Armatures, Bones & Control Rigs

SM Engine features a complete skeletal animation system (BoneRigPanel.js & AdvancedControlRig.js):

  • Armature Add: Insert single bone or humanoid biped skeleton preset.
  • Pose Mode: Manipulate individual bone rotations and IK (Inverse Kinematics) targets.
  • Inverse Kinematics (IK): Move hand or foot targets to automatically calculate arm/leg joint angles.
  • Weight Painting: Paint vertex influence weights (0.0 to 1.0) for smooth mesh skinning.

Motion Matching & Character Locomotion

The ual2_motion_matching.js system dynamically selects animation frames from a clip database matching desired player velocity, acceleration, and trajectory path — providing seamless fluid locomotion without manual blend trees.
