Asset Management & Scene Persistence

Technical guide to SM Engine's Asset Panel, GLTF model importing, built-in model library, and scene JSON serialization.

Asset Panel & Library

Open the Asset Panel from the left sidebar or press Shift + A → Asset Library to drag and drop assets directly into your 3D scene:

  • Built-in Primitives: Cube, Sphere, Cylinder, Cone, Torus, Plane, Monkey (Suzanne).
  • Architectural Props: Doors, Windows, Fences, Stairs, Roof tiles.
  • Vegetation Models: Trees, Palms, Grass tufts, Rocks, Boulders.

Scene Serialization & JSON Save/Load

The ScenePersistenceManager.js serializes complete 3D scene states into a clean human-readable .smproj JSON schema: 

{
  "version": "1.0.0",
  "metadata": { "title": "My Scene", "created": "2026-08-07" },
  "environment": { "skyTime": 14.5, "fogDensity": 0.01 },
  "objects": [
    {
      "uuid": "mesh_cube_01",
      "name": "Main Cube",
      "type": "Mesh",
      "transform": { "position": [0, 1, 0], "rotation": [0, 0, 0], "scale": [1, 1, 1] },
      "material": { "color": "#f59e0b", "roughness": 0.3, "metalness": 0.8 }
    }
  ]
}
