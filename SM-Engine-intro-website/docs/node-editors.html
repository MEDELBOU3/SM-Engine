Visual Node Graphs System

Technical documentation for SM Engine's dockable Graph Workspace, managed by GlobalNodeEditorManager.js across 5 specialized node graph sub-editors.

The Graph Workspace Manager

The GlobalNodeEditorManager provides a tabbed header bar allowing seamless switching between node graph environments:

Node Editor Tab System Module Primary Purpose
Player Logic player-graph.js Visual scripting for character movement, input triggers, collision events, and game state logic.
VFX Composer nodes/vfx/vfx.js Particle emitter configuration, velocity curves, color over lifetime, and sprite effect graphs.
Terrain Generator NodeTerrainEditor.js Procedural heightmap terrain generation (Noise, Hydraulic Erosion, Slope Terracing, Blend Masks).
Material Graph MaterialNodeEditor.js GLSL PBR shader node creation, texture sampling, math ops, and instant compilation.
MetaSound Editor MetaSoundEditor.js Procedural audio synthesis, wave oscillation, audio filters (LPF/HPF), spatial 3D audio graph.

1. Player Logic Graph

Visually program gameplay events without writing raw code:

  • Event Nodes: On Start, On Update (Tick), On Key Press, On Trigger Enter, On Collision.
  • Action Nodes: Apply Impulse/Force, Play Animation Clip, Set Light Color, Spawn Prefab, Destroy Object.
  • Control Flow: Branch (If/Else), Sequence, Gate, For Loop, Delay timer.

2. VFX Particle Composer

Author real-time WebGL particle systems:

  • Spawn Module: Rate per second, Burst count, Cone/Sphere/Box emitter shape.
  • Particle Properties: Lifetime, Initial Velocity, Gravity Scale, Rotation Speed.
  • Color & Alpha Gradient: Fade in/out over normalized particle lifetime (0.0 to 1.0).

3. MetaSound Audio Graph

The MetaSound Editor processes node-based audio synthesis (similar to Unreal Engine MetaSounds):

  • Oscillators: Sine, Square, Sawtooth, Triangle wave audio generators.
  • Audio Filters: Low-Pass Filter (LPF), High-Pass Filter (HPF), Reverb Delay, Gain Volume.
  • 3D Spatial Audio: Attenuation falloff distance curves for positional 3D sound emitters in the scene.
