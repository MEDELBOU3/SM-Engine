Game Development & Standalone Export

Technical guide to SM Engine's Game Mode runtime orchestrator, player controllers, trigger zones, game UI overlays, and standalone executable export.

Game Mode Orchestration

Click Play Game (Ctrl + P) in the top toolbar to switch from Editor View into GameModeManager.js runtime mode:

  • Locks pointer controls and initializes player character camera script.
  • Starts physics world simulation and Player Logic visual node scripts.
  • Press Escape at any time to return to Editor Mode without losing scene changes.

Player Controllers & Cameras

The playable character is the full SMPlayerSystem controller: physics-driven movement, first/third-person camera rig and an animation state machine — only enabled in the GAME_DEV and GAMEPLAY_SAMPLE workspaces. See Player Controller for the API and Gameplay & Sample Mode for the UE-style testing environment.

Controller Mode Camera Type Input Mapping
First-Person (FPS) Mouse-Look Pointer Lock WASD Move, Space Jump, Shift Sprint.
Third-Person (TP) Orbit Follow Camera WASD Move relative to camera direction, Mouse Orbit.
Top-Down / Isometric Fixed Angle Camera Click-to-move pathfinding or 8-way directional keys.

Standalone Game Export System

The game-export-system.js module bundles your project into standalone playable packages:

  • HTML5 Web Bundle: Single self-contained HTML/JS bundle ready for itch.io or web hosting.
  • Desktop Executable (Electron): Packages the runtime engine into a standalone Windows .exe or macOS app bundle.
