Mesh Modeling & Modifier Stack

Technical guide to Edit Mode geometry editing, selection modes, interactive modeling operators, and non-destructive modifiers in SM Engine.

Edit Mode Selection Modes

Press Tab with a mesh object selected to enter Edit Mode. Select geometry elements using the top toolbar icons or numerical hotkeys:

  • 1 Vertex Select: Select individual vertex points in 3D space.
  • 2 Edge Select: Select line segments connecting vertices.
  • 3 Face Select: Select planar polygonal faces (triangles, quads, n-gons).

Core Modeling Operators

Operator Hotkey Description & Parameters
Extrude Region E Pulls selected vertices, edges, or faces outward along their averaged surface normals.
Loop Cut & Slide Ctrl + R Inserts a ring of new edge loops around quad topology. Use scroll wheel to increase cut count.
Inset Faces I Creates an inner offset boundary inside selected faces. Toggle Individual mode for multi-face inset.
Bevel Edges/Verts Ctrl + B Rounds off sharp mesh edges by inserting chamfered sub-faces and segments.
Knife Tool K Draws precise custom cut lines across polygon faces in real-time. Press Enter to confirm cut.
Bridge Edge Loops Menu / Command Connects two open edge loop selections with spanning quad faces.
Subdivide Mesh Right-Click → Subdivide Splits selected edges and faces in half, doubling polycount and adding smoothness.
Merge Vertices M Combines multiple selected vertices into a single vertex (At Center, At Cursor, By Distance).

Non-Destructive Modifier Stack

Modifiers are automated procedural operations applied dynamically to a mesh without altering its underlying vertex data. Modifiers can be stacked, reordered, toggled on/off, or applied permanently:

1. Subdivision Surface

Uses Catmull-Clark algorithm to smooth out hard geometry by recursively subdividing quad faces. Adjustable Viewport & Render levels (1-5).

2. Array Modifier

Duplicates the mesh multiple times along a specified offset vector or relative object bounds (e.g. building fences, stairs, columns).

3. Mirror Modifier

Mirrors geometry non-destructively across X, Y, or Z local axes with automatic vertex merging along the center seam.

4. Bevel Modifier

Applies smooth rounded chamfers to all sharp edges across the object based on angle thresholds (e.g. 30° limit).

5. Boolean Modifier

Executes constructive solid geometry (CSG) operations: Difference (carve hole), Union (combine), and Intersect.

6. Solidify Modifier

Gives thickness to thin 2D surface meshes by extruding all faces inward or outward by a set distance parameter.

7. Curve Deform

Bends and deforms a mesh along a 3D Bezier or NURBS path curve (ideal for pipes, roads, tentacles).

8. Decimate Modifier

Reduces vertex count while preserving overall mesh silhouette — essential for LOD creation and game optimization.

9. Weld Modifier

Automatically merges vertices that fall within a specified proximity distance threshold.

Advanced Architecture & Profile Generators

SM Engine includes specialized parametric generators for architectural workflows:

  • Wall & Window Generator: Procedural wall extrusion with automatic window frame cutouts.
  • 2D Profile Extruder: Draw custom 2D vector shapes and sweep them along 3D paths for crowns, moldings, and pipes.
  • Spin & Screw Tools: Revolve 2D profiles around a central axis to generate cylindrical lathe objects (vases, cups, screws, spiral staircases).
