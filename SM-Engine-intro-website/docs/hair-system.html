Hair & Fur Grooming System

The Hair & Fur Grooming System in SM Engine provides tools and shaders for creating realistic hair, fur, and fibrous materials on 3D meshes. It includes specialized grooming brushes, physics simulations, and advanced rendering models.

Kajiya-Kay Anisotropic Hair Shader

The core rendering model relies on the Kajiya-Kay shading algorithm to produce dual specular highlights and anisotropic reflections that give hair its characteristic shine and depth.

Note: The hair shader requires forward rendering for optimal transparency sorting, though depth pre-passes can mitigate overdraw in complex grooms.

Shader Properties

Parameter Type Description
BaseColor Color (RGB) The diffuse color of the hair strands.
SpecularPrimary Color (RGB) Color of the direct reflection from the light source.
SpecularSecondary Color (RGB) Color of the secondary highlight caused by internal scattering.
Shininess Float Controls the glossiness and sharpness of the highlights.
TipFade Float (0.0 - 1.0) Alpha blending value at the tip of the strand to create softness.

Hair Brushes

Grooming is performed using a specialized set of brushes within the Sculpting workspace.

Add Brush

The Add Brush scatters hair strands onto the target mesh surface. It respects masking and can be modulated by pressure sensitivity if using a drawing tablet.

  • Density: Number of strands added per stroke.
  • Initial Length: Starting length of the newly added strands.

Comb Brush

The Comb Brush is a directional tool used to orient hair strands along the mesh surface contours.

  • Strength: How forcefully strands follow the brush stroke direction.
  • Preserve Length: If enabled, prevents the comb brush from stretching strands.

Cut Brush

The Cut Brush trims the length of strands within the brush radius, useful for styling and defining the silhouette.

Smooth Brush

The Smooth Brush relaxes hair strand curvature, removing kinks and creating a more uniform appearance.

Verlet Physics Simulation

SM Engine uses a fast Verlet integration physics model for real-time hair dynamics. This provides realistic motion with low overhead.

Dynamics Settings

  • Gravity: Downward force applied to the strands.
  • Stiffness: Resistance to bending, determining how much a strand tries to return to its groomed shape.
  • Friction: Damping force applied to strand movement to simulate air resistance and friction between strands.

Collision Detection

The system performs collision detection against the target body mesh to prevent hair from clipping through the character's head or body. Spherical or capsule colliders can be attached to bones for faster evaluation.

Wind Interaction

Hair strands automatically interact with global wind forces defined in the Environment settings, creating dynamic, flowing motion in gameplay or rendering.

Performance Settings

To ensure high frame rates, the hair system provides several optimization parameters.

  • Strand Count: Up to 50,000 strands can be rendered efficiently.
  • Segments per Strand: Defines the resolution of each hair (e.g., 8 segments).
  • BufferGeometry Allocation: The system pre-allocates BufferGeometry to prevent garbage collection stutters during simulation or grooming.

Scripting API Example

const hairSystem = new SM.HairSystem({
    maxStrands: 50000,
    segments: 8,
    shader: SM.HairShaders.KajiyaKay
});

hairSystem.setMaterial({
    baseColor: new SM.Color(0.2, 0.1, 0.05),
    shininess: 40.0,
    tipFade: 0.8
});

hairSystem.enablePhysics({
    stiffness: 0.6,
    gravity: 9.8,
    collisionMesh: playerBody
});

scene.add(hairSystem);
