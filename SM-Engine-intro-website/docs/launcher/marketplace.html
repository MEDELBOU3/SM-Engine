Marketplace & Library

Browse BlendSwap and manage your local asset library without leaving the launcher. The marketplace is powered by BlendSwapMainService and the library by AssetLibraryManager.

BlendSwap Marketplace

The Marketplace view is created by MarketplaceView and backed by MarketplaceManager. The main process creates the service via createBlendSwapMarketplaceService({ app, ipcMain, projectManager, getWindow, rootDir }) and registers its IPC handlers via blendSwapMarketplace.register().

From the UI you can search BlendSwap, preview assets, and download them. Downloads are stored locally and then appear in your Library for use in any project.

Asset Library

The Library view is driven by LibraryView and AssetLibraryManager. On startup, the launcher calls assetLibraryManager.load() to index your local library. Assets are associated with projects via ProjectManager, so the same asset can be reused across multiple projects.

Component File Purpose
Marketplace UI src/ui/views/MarketplaceView.js Search and download from BlendSwap.
Library UI src/ui/views/LibraryView.js Manage downloaded assets locally.
Marketplace Manager src/managers/MarketplaceManager.js Coordinates marketplace state in the renderer.
Library Manager src/managers/AssetLibraryManager.js Indexes and serves local assets.
Main Service electron/BlendSwapMainService.js Handles downloads and file placement in the main process.

Typical flow

  1. Open Marketplace, search for an asset, and download it.
  2. Open Library to see the downloaded asset and its files.
  3. Launch a project and import the asset via the engine's asset pipeline.
