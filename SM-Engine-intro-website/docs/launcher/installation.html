Installation & Setup

Install the SM Engine Launcher on Windows, choose your distribution format, and verify the backend connection.

Requirements

Item Details
OS Windows 10/11 x64
Runtime Electron 31 (bundled) — no separate install
Network Required for engine downloads and BlendSwap marketplace
Source launcher/package.json — productName: SM Engine Launcher, appId: com.smengine.launcher

Distribution formats

The launcher is built via electron-builder (launcher/package.json → build):

Target Artifact Notes
NSIS Installer SM-Engine-Launcher-Setup-1.0.2-x64.exe Allows custom install directory, desktop/start-menu shortcuts, and run-after-finish.
Portable SM-Engine-Launcher-Portable-1.0.2-x64.exe Single executable, no install — run from any folder.
Zip SM-Engine-Launcher-1.0.2-x64.zip Manual extract and run.
Scripts npm start runs Electron directly, npm run pack builds a directory, npm run dist and npm run dist:win produce the distributables.

First run checklist

  1. Launch the app — the window is 1360×820, with a sandboxed renderer and context isolation (electron-main.js → webPreferences).
  2. Check Diagnostics for launcher version, Electron/Chrome versions, and system info.
  3. Go to Engine Versions and confirm at least one engine build is detected or installed.
  4. Create a test project to verify ProjectService and ProjectManager can write to your chosen folder.

Verify the installation

Open the launcher and check the Engine status in the top bar. If it shows Ready and the version matches SM Engine 1.0.1, the backend (EngineLauncherService) is connected.
