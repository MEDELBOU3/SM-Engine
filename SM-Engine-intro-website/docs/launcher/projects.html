Projects

Create, import, and launch SM Engine projects from the launcher. All project state is local and managed by ProjectManager and ProjectService.

Create a new project

Click New Project and choose a template. The launcher calls project:create (main process) which delegates to ProjectService.createProject():

Template Category What you get
Empty Project General Minimal scene with a clean project structure.
First Person Game Starter layout for first-person gameplay.
Third Person Game Character, camera and movement starter.
Film / Cinematic Film Cinematic-oriented project and sequencing workflow.

The service creates the folder, writes the project manifest, and registers it via ProjectManager.add(). The new project appears immediately in Projects and is tracked for analytics.

Add an existing project

Use Open Project and select a folder. The launcher runs project:addExisting → ProjectService.inspectProject(path) to read the manifest and then registers it. If the folder is not a valid SM Engine project, the launcher shows an error instead of adding it.

Launch a project

Click Launch on a project card. The renderer sends project:launch with projectId, gpuMode and safeMode. The main process looks up the project, calls EngineLauncherService.launch({ projectPath, gpuMode, safeMode }), and updates the project's lastOpenedAt via ProjectManager.touch().

Safe Mode Launch with safeMode: true to start the engine with a minimal configuration — useful when a project has faulty plugins or settings.

Manage the list

Action IPC Effect
List project:list Returns all projects from ProjectManager.list().
Remove project:remove Removes the project from the launcher list only — project files on disk are not deleted.
Search Renderer only Filters the current view via searchQuery in the UI.
