Troubleshooting

Diagnose common launcher issues using the built-in diagnostics, logs, and the secure IPC shell.

Diagnostics view

Open Diagnostics in the launcher. It calls launcher:getDiagnostics and shows:

Section Source What it tells you
Launcher app.getVersion(), process.versions Launcher version, Electron and Chrome versions.
System os module Platform, arch, CPU, memory, and OS release.
Engine EngineLauncherService.detectInstallation() Whether an engine build is found and where.

Use Copy Diagnostics to copy a summary to the clipboard for bug reports.

Common issues

Symptom Check Fix
Engine does not launch Engine path in SettingsManager Verify the path in Settings or set SM_ENGINE_DEV_PATH.
Project fails to open Project folder and manifest Use Add Existing Project to re-inspect the folder.
Download stalls Network and UpdateService logs Cancel and retry, or check GitHub access to MEDELBOU3/SM-Engine.
“No app associated” for links URL handling The launcher now routes https:// via shell.openExternal — update to the latest build if you see this.
Window does not show Electron window state Delete the launcher's settings file (via SettingsManager path) and restart.

Logs and support

Run the launcher from a terminal with npm start to see main-process logs. The renderer logs appear in the DevTools console (enable via Settings → DevTools if needed). For persistent issues, copy diagnostics and open an issue on GitHub SM-Engine.
