Interface & Layout Reference

Comprehensive overview of the SM Engine user interface components, panel docking system, viewport gizmos, and workspace tabs.

Main Interface Regions

The workspace consists of five core flexible regions:

  • Top Header Menu Bar: File, Edit, Add, Render, Window, Help menus, and Workspace Tab Selector (Layout, Modeling, Scripting, Graph Workspace, 2D Animation).
  • Left Tools Panel: Mode-specific creation tools (Select, Move, Rotate, Scale, Extrude, Loop Cut, Sculpt Brushes).
  • Central 3D Viewport: WebGL interactive scene canvas with 3D orientation gizmo, grid plane, camera overlays, and context menus.
  • Right Sidebar (Hierarchy & Inspector): Outliner scene graph tree on top, Object/Material/Physics Inspector properties panel on bottom.
  • Bottom Drawer (Timeline / Node Graph): Dockable timeline with keyframes, playback controls, graph editor, spreadsheet data, or visual node graph wrappers.

Inspector Panel Tabs

When an object is selected in the 3D Viewport or Hierarchy Outliner, the Inspector displays detailed property tabs:

1. Transform Tab

Exact X/Y/Z numerical values for Position, Rotation (Euler degrees or Quaternion), Scale, Dimensions, and Origin Point alignment.

2. Material Tab

Assigned material slots, PBR base color, metallic/roughness sliders, emission color, transparency, and Shader Editor launcher.

3. Physics Tab

Rigid Body type (Dynamic, Static, Kinematic), mass, friction, restitution (bounciness), collision shapes (Box, Sphere, Convex Mesh).

4. Modifiers Tab

Stack of non-destructive procedural modifiers: Subdivision Surface, Mirror, Array, Bevel, Boolean, Solidify, Decimate.

Multi-View Split Screen

Click the Split View button in the viewport header to divide the canvas into 2-viewport or 4-viewport orthographic split views (Top, Front, Side, Perspective), ideal for precision architectural modeling and animation posing.
