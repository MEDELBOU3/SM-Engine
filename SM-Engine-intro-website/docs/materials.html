Material Node Editor & Shader Graph

Complete reference for SM Engine's node-based material authoring system, Principled BSDF shader model, and GLSL code injection framework.

Principled BSDF Node

The Principled BSDF node combines multiple physically-based rendering layers into a single comprehensive shader node (similar to Disney / Blender Principled BSDF):

Socket Name Type Default PBR Description
BaseColor Color / vec3 #ffffff Surface albedo color or diffuse texture input.
Metallic Float (0-1) 0.00 Blends between dielectric (0) and metallic (1) reflection behavior.
Roughness Float (0-1) 0.50 Controls specular reflection microfacet sharpness.
Opacity Float (0-1) 1.00 Alpha transparency level (requires transparent: true).
Emission Color / vec3 #000000 Self-illuminating emissive radiance color.
EmissionStrength Float 0.00 Multiplier scale for self-illumination radiance.
Transmission Float (0-1) 0.00 Glass transparency refractivity layer.
IOR Float (1-2.5) 1.50 Index of refraction for transparent materials (Water: 1.33, Glass: 1.5, Diamond: 2.42).
Clearcoat Float (0-1) 0.00 Extra glossy specular coating layer (car paint, lacquered wood).
Normal Vector3 null Tangent-space normal map vector input.

Complete Shader Node Reference

Node Name Category Outputs Function
Float Value Value float Outputs a single scalar floating point value with slider.
RGB Color Value vec3 Outputs a hex color picker vec3 (R, G, B).
Texture Sampler Texture vec3 / float Samples 2D texture maps (Albedo, Roughness, Normal, Metallic, AO).
UV Map Input vec2 Outputs surface mesh UV texture coordinates (vUv).
Time Input Input float Outputs global elapsed scene time multiplier for animation.
Math (Add/Sub/Mul/Div) Math float Performs scalar math operations between two float inputs.
Math (Sin/Cos/Power/Sqrt) Math float Trigonometric and exponential GLSL mathematical functions.
Mix (Color / Float) Vector vec3 / float Linear interpolation (mix) between inputs A and B based on Alpha factor.
Fresnel Vector float Calculates Schlick's Fresnel reflection factor based on view angle and IOR.
Panner UV vec2 Animates UV coordinate offsets over time (water flow, scrolling screens).
Tiling & Offset UV vec2 Scales TileX/TileY and Offsets X/Y for UV map coordinates.
Color Ramp Color vec3 Maps a scalar float input onto a multi-stop color gradient.
Water Waves Fluid vec3 / float Procedural wave height displacement and normal distortion.

GLSL Code Generation Engine

When Apply to Object or Auto-Compile is active, MaterialNodeEditor.js performs a topological sort of the graph node order, resolves variable type coercions (e.g. converting float scalar to vec3(f, f, f) for grayscale BaseColor input), and injects GLSL code directly into Three.js onBeforeCompile shader chunks: 

// Sample generated GLSL shader injection chunk
float node_5_0 = 0.5000;
vec3 node_3_0 = texture2D(uTex_node_3, vUv).rgb * 1.0000;

#include <color_fragment>
diffuseColor.rgb = node_3_0 * vec3(node_5_0, node_5_0, node_5_0);
