Geometry Nodes

The Geometry Nodes system in SM Engine is a powerful, node-based visual programming interface for procedural generation, modification, and manipulation of geometry. By utilizing a non-destructive workflow, you can build complex parametric assets, procedurally scatter foliage, scatter instances, manipulate curves, and construct mathematical rules for your scene elements without permanently altering the base mesh.

Note: Geometry Nodes operate within the modifier stack. They are processed sequentially along with other modifiers, meaning you can place a Geometry Nodes modifier before or after a standard Subdivision Surface modifier for differing results.

Getting Started with Geometry Nodes

To begin using Geometry Nodes on an object:

  1. Select the object you want to modify in the 3D viewport or Outliner.
  2. Navigate to the Modifiers tab in the Properties panel.
  3. Click Add Modifier and choose Geometry Nodes.
  4. Open the Geometry Nodes Workspace from the top workspace bar, or split a view and select the Geometry Node Editor.
  5. Click New in the node editor header to create a new node tree. This will automatically generate a Group Input and Group Output node.

Node Reference Guide

The system comprises hundreds of specialized nodes organized into logical categories within the nodes/geometry-nodes/registry/ core architecture.

Input Nodes (utility.js)

Input nodes supply raw data, constants, and fields to the node tree.

Node Name Description
Group InputPasses base geometry or user-defined parameters into the node tree.
Group OutputThe final geometry output rendered to the screen. Can also output calculated fields.
Float/ValueNumeric float slider (0.0 - 1.0 default).
IntegerInteger number input.
BooleanTrue/False toggle.
VectorXYZ vector input (3 float sockets).
ColorStandard RGBA color picker.
PositionPer-point spatial coordinate field. Domain: POINT.
NormalPer-point normal vector field. Domain: POINT.
IndexPer-point integer index field.
Named AttributeRead geometry attributes by their string name (e.g., "uv_map", "vertex_colors").

Primitive Nodes (primitives.js)

Generate base geometry directly within the node tree, overriding or adding to the input geometry.

Node Name Parameters / Inputs Description
Mesh GridWidth, Height, Subdivisions X/YPlanar grid mesh divided into quads.
CubeSize X, Y, ZStandard box primitive.
UV SphereRadius, Segments, RingsSphere built with latitude/longitude topology.
Ico SphereRadius, SubdivisionsSphere built with subdivided triangles. Better for even vertex distribution.
CylinderRadius, Height, Segments, Cap (Bool)Cylindrical tube with optional capped ends.
ConeRadius Top/Bottom, Height, SegmentsCone or frustum.
TorusMajor/Minor Radius, SegmentsDonut shape topology.
CircleRadius, Segments, Fill type2D circle. Fill types include None, Ngon, Triangle fan.
LineStart Vec, End Vec, ResolutionA single edge subdivided by Resolution.
Bezier SegmentStart/End HandlesA single mathematical bezier curve segment.

Modify Nodes (modify.js)

Nodes that alter the topological structure of meshes.

Node Name Description
Subdivide MeshApplies Catmull-Clark subdivision based on the Level integer input.
TriangulateConverts ngons and quads to triangles. (Min Vertices threshold parameter).
Merge by DistanceWelds vertices that fall within a specified Threshold radius. Great for cleanup.
Set PositionOverrides point positions using a vector field. Ideal for displacement.
Extrude MeshExtrudes faces, edges, or vertices based on an Offset vector and Individual toggle.
Bevel MeshApplies edge bevels using Amount, Segments, and Limit type parameters.
Boolean GeometryPerforms Union, Difference, or Intersect operations between two geometry inputs.
Delete GeometryDeletes components (faces/edges/verts) dictated by a boolean Selection field.
Duplicate ElementsClones geometry elements a specified number of times.
Scale ElementsScales faces, edges, or verts independently from their centers.
Flip FacesReverses face normals.
Split EdgesSplits connected edges, resulting in hard normals.
Fill CurveCreates flat 2D faces derived from a closed curve outline.

Transform Nodes (transform.js)

Spatial manipulation of geometry and instances.

  • Transform Geometry: Applies uniform translation, rotation, and scale to the entire geometry input.
  • Translate Instances: Moves instanced geometry based on a vector field.
  • Rotate Instances: Rotates instanced geometry.
  • Scale Instances: Scales instanced geometry.
  • Align Euler to Vector: Math utility to align an object's rotation so that one of its local axes points towards a target vector.

Topology Nodes (topology.js)

Read advanced topological data for masking and logic.

  • Vertex Neighbors: Outputs the count of connected vertices for each vertex.
  • Face Area: Calculates the surface area of faces as a float field.
  • Edge Angle: Outputs the dihedral angle between two adjacent faces. Useful for edge-wear masks.
  • Is Face Planar: Boolean field returning true if all vertices of a face lie on the same plane.

Instances Nodes (instances.js)

Instancing is crucial for performance. It allows thousands of duplicates of an object to be drawn with a single draw call.

Node Name Description
Instance on PointsScatters an Instance geometry at every point of the base geometry.
Realize InstancesConverts lightweight instances into actual, unique mesh data. Use with caution.
PointsGenerates a raw point cloud from an integer count or extracts points from geometry.
Performance Tip: Realize Instances
Instancing (e.g., using Instance on Points) is highly optimized. If you scatter 10,000 trees, the engine only keeps 1 tree in memory. However, if you use Realize Instances, the engine generates real geometry for all 10,000 trees, which can cause massive memory spikes and lag. Only realize instances if you absolutely must deform or modify the scattered copies individually.

Curve Nodes (curve.js)

Spline and curve manipulation logic.

  • Curve to Mesh: Converts a 1D curve into a 3D mesh by sweeping a Profile Curve along it.
  • Resample Curve: Rebuilds the curve to have a specific point Count or consistent Length between points.
  • Subdivide Curve: Adds intermediate control points to curve segments.
  • Set Curve Radius: Sets a per-point radius field. When used with Curve to Mesh, this drives the tube thickness.
  • Curve Length: Outputs the total arc length of the spline.
  • Endpoint Selection: Generates a boolean mask selecting only the start and end points of curve strands.

Attribute Nodes (attributes.js)

  • Store Named Attribute: Bakes a procedural field into the geometry vertex/face data under a specific string name.
  • Remove Named Attribute: Deletes an attribute to free up memory.
  • Domain Size: Returns the total count of Points, Edges, Faces, or Splines in the geometry.

Field/Math Nodes (fields.js)

These perform the core mathematical logic driving procedural systems.

Node Name Operations
MathAdd, Subtract, Multiply, Divide, Power, Sqrt, Abs, Floor, Ceil, Fract, Sin, Cos, Tan, Log, Min, Max, Clamp, Snap, Wrap, Ping-Pong, Modulo, Round.
Vector MathAdd, Subtract, Multiply, Cross Product, Dot Product, Normalize, Length, Scale, Distance.
Boolean MathAND, OR, NOT, XOR, NAND, NOR.
CompareLess than, Greater than, Equal, Not Equal, Less/Equal, Greater/Equal.
SwitchActs as an IF statement, outputting A or B based on a boolean condition.
Map RangeRemaps values from one range to another (Linear, Stepped, Smoothstep).
ClampRestricts a value between a Min and Max limit.
Random ValueGenerates noise-free random floats, vectors, or integers based on a Seed and ID.
Accumulate FieldCalculates a running total of a field across indices.

Material Nodes (material.js)

  • Set Material: Assigns a specific Material asset to the geometry.
  • Set Material Index: Assigns an integer material slot index per face.
  • Material Index: Reads the existing material index.
  • Material Selection: Creates a boolean mask selecting faces with a specific material index.

Noise & Texture Nodes (fields.js)

Procedural textures for displacement, masking, and colors.

  • Noise Texture: Standard fractal Perlin-style noise. Parameters: Scale, Detail, Roughness, Distortion, Octaves.
  • Voronoi Texture: Cellular noise outputting Distance or Color. Parameters: Scale, Randomness, Feature (F1, F2, F2-F1).
  • Wave Texture: Generates repeating bands or rings. Parameters: Scale, Distortion, Detail.
  • Gradient Texture: Linear, Radial, Spherical, or Diagonal gradient mappings.
  • White Noise: Completely uncorrelated random values per coordinate.

Utility Nodes (utility.js)

  • Frame: Visual container to group nodes together and add comments for organization.
  • Reroute: A visual dot to neatly organize long connecting cables.
  • String to Curves: Generates 2D curve representations of text strings. Parameters: Font, Size, Character Spacing.
  • Geometry to Instance: Wraps arbitrary geometry geometry into a single instance reference.

Workflow Examples

Example 1: Procedural Stone Wall

Using nodes to create a brick-like wall pattern that is easily configurable:

  1. Start with a Mesh Grid.
  2. Use a Split Edges node to disconnect the quads.
  3. Pass the geometry to a Scale Elements node, set to scale Faces by 0.95 to create mortar gaps.
  4. Use an Extrude Mesh node to give the bricks depth.
  5. Connect a Noise Texture into the Offset of a Set Position node to apply a slight rocky displacement to the bricks.

Example 2: Scattering Vegetation on Terrain

A classic use case for Geometry Nodes is distributing props over a surface:

  1. Add a Group Input (your terrain mesh).
  2. Connect it to an Instance on Points node.
  3. Drag a grass mesh from the Asset Browser into the node editor. This creates a node representing that mesh. Plug it into the Instance socket.
  4. To randomize the grass, add a Random Value node (Type: Vector) and plug it into the Rotation socket. Set the min/max Z values from 0.0 to 6.28 (2 Pi radians).
  5. Add another Random Value node (Type: Float) and plug it into the Scale socket to randomize grass size between 0.8 and 1.2.
