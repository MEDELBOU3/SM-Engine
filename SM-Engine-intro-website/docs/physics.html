Physics Simulation & Collisions

Technical guide to rigid body dynamics, collision primitive shapes, constraints, and physics world settings in SM Engine.

Rigid Body Component Types

Body Type Description Common Usage
Dynamic Fully simulated body affected by gravity, forces, impulses, and collisions. Crates, debris, projectiles, physics obstacles.
Static Immovable object that acts as a collision boundary. Zero performance cost during movement checks. Floors, walls, terrain, static architecture.
Kinematic Driven manually by code or keyframed animation while pushing away dynamic rigid bodies. Moving platforms, elevators, doors, conveyor belts.

Collision Shapes & Performance

  • Box Collider: Extremely fast primitive bounding box.
  • Sphere Collider: Fast analytical sphere distance check.
  • Capsule Collider: Ideal for character player controllers (avoids getting stuck on steps).
  • Convex Mesh: Auto-computes a tight convex hull around complex meshes.
  • Trimesh Collider: Exact polygon mesh collision (recommended for static terrain only).

Physics World Parameters

Configure world settings in Physics Panel:

  • Gravity Vector: Default (0, -9.81, 0) m/s².
  • Substeps / Solver Iterations: Higher solver iterations (e.g. 10) prevent fast-moving objects from passing through thin walls (tunnelling).
