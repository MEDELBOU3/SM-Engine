Physics & Dynamics

SM Engine features a robust, multithreaded rigid body and soft body physics system powered by the underlying PhysicsSystem.js integration. Whether you are building gameplay interactions, simulated destruction, or realistic vehicles, the physics engine provides the tools you need.

Physics Body Types

Every physics object in the scene must be categorized into one of three behavioral types:

  • Dynamic: Objects that respond to forces, gravity, and collisions. Their transform is entirely controlled by the physics simulation. (e.g., A bouncing ball, a wooden crate).
  • Static: Immobile objects that do not move but act as collision boundaries for dynamic bodies. They have infinite mass. (e.g., Floors, walls, terrain).
  • Kinematic: Objects that act like static bodies to other objects, but can be moved via script or animation. They push dynamic bodies out of the way but are unaffected by gravity or forces. (e.g., Moving platforms, animated character controllers).

Collision Groups & Masks

Collision groups determine which objects can physically interact with each other. By default, the engine uses bitmasking to allow fine-grained control.

  • NONE (0): Collides with nothing.
  • DEFAULT (1): Standard dynamic/static geometry.
  • GROUND (2): Terrain and main floor meshes.
  • KINEMATIC (4): Moving platforms and controllers.
  • LIQUID (8): Water volumes and buoyancy triggers.
  • SENSOR (16): Non-solid trigger volumes (ghost objects).
  • ALL (-1): Collides with everything.

Advanced Physics Features

Spatial Forces & Zones

SM Engine includes specialized volume objects that apply continuous forces to dynamic bodies that enter them:

  • Wind Zones: Applies a directional force with optional turbulence. Visualized in the editor with 3D helper gizmos indicating flow direction.
  • Liquid Zones: Enables SPH-based fluid simulation calculations. Dynamic objects entering the volume will calculate buoyancy based on their density and volume, resulting in realistic floating.
  • Attractors: Spherically symmetrical gravity-well effects. Attracts objects toward a central point.
  • Force Fields: Radial repulsion fields that push bodies away.
  • Vortex Forces: Applies a spinning, tangential force around a central axis, creating a tornado-like effect.

Explosion Forces

Trigger instant radial forces via scripting using the Explosion API. You can define an origin point, a radius, and a force magnitude. The force dissipates based on the inverse-square law.

Constraints & Joints

You can mechanically link rigid bodies together using constraints:

  • Hinge: Restricts movement to a single rotational axis (e.g., a door).
  • Ball-Socket: Allows full rotation but locks position (e.g., a trailer hitch).
  • Slider: Allows movement along a single linear axis (e.g., a piston).
  • ConeTwist: A ball-socket joint with angular limits.
  • Generic 6DOF: Fully customizable constraints on all 3 linear and 3 angular axes.

Continuous Collision Detection (CCD)

For fast-moving small objects (like bullets or debris), standard discrete collision detection might fail, causing the object to "tunnel" through walls. Enable CCD on these specific objects. It performs a swept-sphere test along the velocity vector to guarantee a hit.

Soft Bodies

SM Engine supports soft body dynamics via Ammo.js. You can convert a mesh into a cloth or squishy volume. Note: Soft bodies are computationally expensive. Use them sparingly on optimized meshes.

Debug Mode

Enable Physics Debug Mode in the viewport overlays to render wireframes of the actual collision shapes being used by the physics engine, rather than the graphical meshes. This mode also color-codes bodies based on their sleep state (sleeping bodies are disabled to save CPU).
