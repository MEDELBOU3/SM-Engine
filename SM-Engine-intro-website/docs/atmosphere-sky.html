Sky, Atmosphere & Viewports

The Environment system in SM Engine provides physically based atmospheric scattering, dynamic volumetric clouds, and robust viewport management for analyzing and rendering the scene.

Atmospheric Scattering Sky Model

The sky is rendered using a physically based atmospheric scattering model that simulates how light interacts with particles in the air.

Sun Position & Time of Day

The sun's position is driven by solar elevation and azimuth angles. A convenient Time-of-Day slider allows smooth transitions from 0 to 24 hours, automatically updating sun position, sky color, and ambient lighting.

Rayleigh and Mie Scattering

By adjusting scattering parameters, you can simulate various atmospheric conditions:

  • Rayleigh Scattering: Simulates scattering by small molecules. Higher values increase the intensity of blue skies and colorful sunsets.
  • Mie Scattering: Simulates scattering by larger particles (dust, pollution). Controls the haze and the halo size around the sun.

Volumetric Cloud Layer

SM Engine features ray-marched volumetric clouds that react realistically to the sun and ambient light.

Parameter Description
Density The thickness of the clouds.
Coverage How much of the sky is filled with clouds.
Speed The rate at which clouds move across the sky.
Wind Direction The 2D vector controlling cloud movement direction.

Exponential Distance Fog

To blend distant geometry into the sky and create depth, the engine provides exponential distance fog.

  • Density: Overall thickness of the fog.
  • Color: The tint of the fog, often linked to the sky's horizon color.
  • Start/End Distance: Controls where the fog begins and where it reaches maximum opacity.
Tip: Link the fog color to the Atmospheric Scattering horizon output for seamless blending between terrain and sky.

Global Viewport Manager

The GlobalViewportManager.js handles how the scene is displayed during editing.

Quad-View Layout

The interface can be split into a quad-view layout, offering four simultaneous perspectives:

  • Top (XY)
  • Front (XZ)
  • Side (YZ)
  • Perspective (3D)

Shading Modes

Each viewport can operate in different shading modes:

  • Wireframe: Displays mesh edges for structural analysis.
  • Solid: Unlit or simply shaded view for fast modeling.
  • Material Preview: EEVEE-style rendering for real-time PBR material feedback.
  • Rendered: High-fidelity Raytracing or Lumen mode.

Viewport Camera Overlays

To assist in composition, viewports can display overlays:

  • Grid Overlay: Spatial reference grid.
  • Axis Trihedron: World orientation indicator.
  • FOV Cone: Visual representation of camera frustums.
  • Safe Margins: Action and title safe areas for broadcast rendering.

Scripting API Example

const sky = new SM.AtmosphericSky();
sky.setTimeOfDay(18.5); // 6:30 PM
sky.setRayleigh(2.5);
sky.setMie(0.005);

const clouds = new SM.VolumetricClouds({
    density: 0.8,
    coverage: 0.6,
    speed: 1.2
});
scene.environment.add(sky, clouds);

SM.GlobalViewportManager.setLayout(SM.ViewportLayouts.QUAD);
SM.GlobalViewportManager.getViewport(0).setShadingMode(SM.ShadingModes.RENDERED);
