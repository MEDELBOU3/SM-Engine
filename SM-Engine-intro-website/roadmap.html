04 What comes next

The foundation is here.
Now widen the frame.

This is the product direction beyond the current desktop release: faster world building, broader runtimes and an ecosystem other creators can extend.

Release phases · platform bets · community surface
01
Current foundation

Core Launch & Desktop Architecture

Establish the desktop runtime with polygon modeling, real-time node graphs, atmospheric scattering, timeline animation and one-click Windows installers.

  • Desktop editor foundation
  • Modeling and shader workflows
  • Atmosphere, animation and media tools
  • Windows distribution pipeline
NOW
02
Rendering evolution

WebGPU Compute & Voxel Meshing

Move heavier workloads toward WebGPU compute while extending world construction and character systems.

  • WebGPU compute pipelines
  • Dynamic voxel dual-contouring
  • Cave and volumetric terrain workflows
  • Enhanced humanoid inverse kinematics
NEXT
03
Runtime expansion

Multiplayer & Networked Physics

Introduce network-aware gameplay systems and broaden standalone runtime packaging beyond Windows.

  • Networking nodes
  • Client prediction and server ticks
  • Networked physics synchronization
  • Linux and macOS packaging direction
LATER
04
Open ecosystem

Plugin SDK & Community Marketplace

Open the engine to external tools, shared content and broader community-driven workflows.

  • C++ and TypeScript plugin APIs
  • Asset and extension marketplace
  • Community brushes and shader packs
  • Project synchronization direction
